#### 字面量与注释

在python中，像`1`,`'hank'`这样直接写出来的，不需要进行计算的值就被称为字面量

在python中没有常量机制，本质上定义好的常量依旧是一个变量，如：`MAX_AGE = 100` 本质上这里的`MAX_AGE`可以进行修改

python中的注释有以下几种写法，但是多行注释其实是因为没有设计好的多行注释可用，所以直接用字符串字面量作为多行注释
```python
# 这是单行注释
'''
这是多行注释
'''
"""
这也是多行注释
"""
```

并且在python中，文件开头如果需要写文档注释和文档编码注释时，文档编码注释要写在整个文件的第一行，如下

```python
coding=utf-8 # 这里是编码格式注释
"""
这里才是文档注释
"""
```

#### 变量和命名规则

   变量是指向字面量的指针

2. 命名规则

   1. 由字母数字下划线组成的标识符，并且数字不能打头
   2. 区分大小写

   4. 不能和内置函数重名
   5. 最好使用蛇形写法、

#### 数据类型

1. 整型

   1. 整数就是整型
   2. 当一个数字很大时，可以使用下划线将数字分组，让数字更易读，如：`num = 100_999_000_000`
   3. py中的整数的上限取决于执行代码的计算机的内存和处理能力

2. 浮点型

   1. 带小数点的数字就是浮点型
   2. 浮点型可以使用科学计数法表示，如下
      1. `speed_of_sound = 3.4E+2`表示3.4 * 10 ^ 2
      2. `humans_of_earth = 8e10`表示8 * 10 ^ 10
      3. `distance_sun_earth = 1.496E8`表示1.496 * 10 ^ 8
      4. `speed_of_light = 2.998e+8`表示2.998 * 10 ^ 8
      5. `one_ml = 1e-3`表示1 * 10 ^ -3

3. 字符串

   1. 字符串的格式化输出

      1. 使用`+`进行拼接，如：`info = '1' + '2' # info = '12'`
      2. 使用占位符进行占位赋值，如：`info = 'my name is %s' % name`
      3. 使用f-string(format-string)格式化字符串，如：`f'my name is {name}'`

   2. 转义字符

      python中有以下转移字符：

      ```python
      print('\'') # 表示一个单引号
      print('\"') # 表示一个双引号
      print('\t') # 表示一个制表符
      print('\\') # 表示一个反斜杠
      print('\r') # 表示让光标回到本行开头，并且覆盖输出
      print('\n') # 表示换行
      ```

   3. 数据类型转换

      1. 任何类型都可以转为str类型
      2. 转int使用`int(variable)`
      3. 转float使用`float(variable)`

### 运算符

##### 算数运算符

| 运算符 | 含义   | 示例        |
| ------ | ------ | ----------- |
| +      | 加     | 1 + 1 = 2   |
| -      | 减     | 2 - 1 = 1   |
| *      | 乘     | 2 * 2 = 4   |
| /      | 除     | 2 / 2 = 1   |
| //     | 取整除 | 5 // 2 = 2  |
| %      | 取余   | 5 % 2 = 1   |
| **     | 乘方   | 5 ** 2 = 25 |

##### 赋值运算符和符合赋值运算符

| 运算符 | 含义       | 示例                    |
| ------ | ---------- | ----------------------- |
| +=     | 赋值加     | `a += 1 ~  a = a + 1`   |
| -=     | 赋值减     | `a -= 1 ~  a = a - 1`   |
| *=     | 赋值乘     | `a *= 4 ~  a = a * 4`   |
| /=     | 赋值除     | `a /= 1 ~  a = a / 1`   |
| //=    | 赋值取整除 | `a //= 2 ~  a = a // 2` |
| %=     | 赋值取余   | `a %= 1 ~  a = a % 1`   |
| **=    | 赋值乘方   | `a **= 25 ~  a = a**1`  |

##### 比较运算符

| 运算符 | 含义     | 示例             |
| ------ | -------- | ---------------- |
| ==     | 等于     | `1 == 1 # True`  |
| !=     | 不等于   | `1 != 1 # False` |
| >      | 大于     | `1 > 1 # False`  |
| <      | 小于     | `1 < 1 # False`  |
| >=     | 大于等于 | `1 >= 1 # False` |
| <=     | 小于等于 | `1 <= 1 # False` |

> PS：
>
> 1. 以上结果都是bool类型，只有True和False两个值
> 2. 字符串之间进行比较，py会先把字符串变成Unicode编码，然后依次比较
> 3. 如果两个互相比较的字符串有一个是另一个的子串，如：`'abcd'>'abc' # True`，则会比较长度
> 4. 使用ord(variable)可以查看变量的unicode编码
> 5. 使用char(unicode)可以将unicode编码转为字符

##### bool类型

只有两个值分别为True和False，使用`bool(variable)`可以将variable转为bool类型，py中除了`0 '' "" None`四个以外的所有字符都是True

##### 逻辑运算符

| 逻辑运算符 | 含义               | 备注                                                         |
| ---------- | ------------------ | ------------------------------------------------------------ |
| and        | 全真为真，有假则假 | 可以进行短路运算，如`False and 3 / 0`,此处3/0不会报错，因为前面已经是False了，不会计算后面 |
| or         | 有真为真，全假则假 | 可以进行短路运算，如`True or 3 / 0`结果也为True              |
| not        | 取反               |                                                              |

### 流程控制

##### 对比for和while

| while                              | for                                          |
| ---------------------------------- | -------------------------------------------- |
| 条件驱动循环                       | 迭代驱动循环，遍历可迭代对象的每一项         |
| 只要条件为True就循环               | 语法简洁，处理可迭代对象的首选，不容易死循环 |
| 写法灵活，适合不确定循环次数的场景 | 适合一开始就知道要执行多少次的场景           |
| 需要手动维护循环条件，容易死循环   |                                              |

### 函数

###### 函数的基本使用

```python
# define function
def function_name():
    # function_body
    pass

function_name()
```

##### 函数参数

```python
def demo(param1,param2):
    pass
# 基本使用
demo(actual_param1,actual_param2)
# 关键字参数 可以乱序传入
demo(param1=actual_param1,param2=actual_param2)
# 被限制的传参方式
```
